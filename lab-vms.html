Virtual Machines

Unit 05 · Bare Metal Hypervisor

This unit represents the virtualization layer of the lab — a bare metal hypervisor running on dedicated hardware that hosts virtual machines. Currently running a Linux web server that hosts a website, this is the most technically layered component in the rack. A bare metal hypervisor sits directly on the hardware with no underlying operating system, which means the VMs it runs get direct access to the physical resources beneath them — more efficient and more stable than running VMs inside a general-purpose OS.

The choice to run virtual machines rather than dedicated physical hardware for every service is the same logic used in enterprise data centers: consolidation, flexibility, and the ability to spin up, snapshot, and tear down environments without touching physical hardware. What I build and test here directly parallels what I manage professionally with VMware and Hyper-V at Northern Human Services.
